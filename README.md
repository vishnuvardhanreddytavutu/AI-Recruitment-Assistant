# 🤖 AI Recruitment Assistant & Candidate Sourcing Agent

An AI-powered recruitment workflow built with **n8n** to automate candidate resume processing, screening, matching, ranking, and centralized tracking.

## 🚀 Features

- 📄 Accepts a Job Description through an n8n form
- 📂 Retrieves candidate resumes from Google Drive
- 📑 Extracts text from PDF resumes
- 🤖 Uses OpenAI GPT to analyze candidate resumes against the Job Description
- 🧠 Extracts candidate names and skills
- 📊 Generates a match score from 0–100
- 🏆 Ranks candidates based on their match scores
- 📋 Stores candidate results in Google Sheets

## 🔄 Workflow

Job Description
↓
Candidate Resume Collection
↓
PDF Text Extraction
↓
AI Resume Analysis
↓
Skills Extraction
↓
Match Score
↓
Candidate Ranking
↓
Google Sheets

## 🛠️ Technologies

- n8n
- OpenAI GPT
- JavaScript
- Google Drive
- Google Sheets
- PDF Processing
- JSON

## 🎯 Project Objective

The objective of this project is to automate repetitive recruitment screening tasks by processing candidate resumes, comparing candidate skills with job requirements, generating match scores, and organizing candidates based on their scores.

## 📌 Project Status

Implemented as an n8n-based recruitment automation workflow.

## 🔐 Security

The public repository does not contain private credentials, API keys, personal candidate information, or private Google Drive/Google Sheets data.
